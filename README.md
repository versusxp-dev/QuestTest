# QuestTest - Текстовая приключенческая игра

**Версия:** 0.1 (MVP)

Текстовая приключенческая игра с ASCII-графикой и интерактивным меню. Погрузитесь в атмосферное путешествие через заброшенные комнаты, тёмные леса и загадочные пещеры.

## 🎮 Особенности

- **ASCII-графика**: Визуальное оформление сцен с помощью символов и эмодзи
- **Интерактивное меню**: Навигация с помощью цифр (1-5) или стрелок вверх/вниз
- **Система состояний**: Сохранение прогресса, инвентарь и флаги сюжета
- **Несколько локаций**: Главная комната, лес, пещера
- **Адаптивный рендеринг**: Корректное отображение на терминалах любого размера

## 🚀 Быстрый старт

### Требования

- Python 3.6+
- Модуль `wcwidth` для корректного отображения символов

### Установка зависимостей

```bash
pip install wcwidth
```

### Запуск игры

```bash
python main.py
```

## 🎯 Управление

| Клавиша | Действие |
|---------|----------|
| `1-5` | Выбор пункта меню |
| `↑` / `↓` | Навигация по меню |
| `Enter` | Активировать выбранный пункт |
| `Q` | Выход из игры |


## 🗺️ Локации

- **Главное меню** - Начало игры, настройки, информация
- **Комната** - Старая заброшенная комната с дверью, сундуком и лампой
- **Лес** - Тёмный лес с тропинкой, деревьями и ручьём
- **Пещера** - Подземная пещера со светящимися кристаллами

## ⚙️ Технические детали

### Рендеринг

Игра использует фиксированный холст 100×40 символов, разделённый на зоны:
- **Зона изображения** (12 строк) - ASCII-арт локации
- **Зона текста** (12 строк) - Описание ситуации
- **Зона меню** (10 строк) - 5 пунктов выбора

### Обработка эмодзи

Модуль `wcwidth` обеспечивает корректный расчёт ширины символов, включая эмодзи и специальные Unicode-символы.

## 🛠️ Разработка

### Добавление новой локации

1. Добавьте ASCII-арт в `assets.py`:
```python
ASCII_ART["new_location"] = """ваш арт"""
```

2. Добавьте описание:
```python
SCENE_DESCRIPTIONS["new_location"] = ["строка 1", "строка 2"]
```

3. Добавьте пункты меню:
```python
MENU_OPTIONS["new_location"] = ["опция 1", "опция 2", ...]
```

4. Создайте обработчик действий в `logic.py`:
```python
def handle_new_location_action(option_index, state):
    # ваша логика
```

5. Зарегистрируйте обработчик в `SCENE_HANDLERS`.
