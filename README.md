# QuestTest - Текстовая приключенческая игра

**Версия:** 1.0 (Engine + Cartridge Architecture)

Текстовая приключенческая игра с ASCII-графикой и интерактивным меню. Погрузитесь в атмосферное путешествие через заброшенные комнаты, тёмные коридоры и загадочные локации.

## 🎯 Архитектура 1.0: Движок + Картридж

Начиная с версии 1.0, проект использует профессиональную архитектуру разделения кода и контента:

- **Движок (Engine)**: `main.py`, `renderer.py` — интерпретатор, который загружает и исполняет сценарий
- **Картридж (Cartridge)**: `scenario.json` — файл с сюжетом, локациями, текстами и переходами

Это позволяет создавать новые игры, просто меняя `scenario.json`, без изменения кода движка.

## 🎮 Особенности

- **ASCII-графика**: Визуальное оформление сцен с помощью символов и эмодзи
- **Интерактивное меню**: Навигация с помощью цифр (1-5) или стрелок вверх/вниз
- **Система состояний**: Сохранение прогресса, инвентарь и флаги сюжета
- **Несколько локаций**: Главная комната, лес, пещера
- **Адаптивный рендеринг**: Корректное отображение на терминалах любого размера

## 🚀 Быстрый старт

### Требования

- Python 3.6+
- Модуль `wcwidth` для корректного отображения символов

### Установка зависимостей

```bash
pip install wcwidth
```

### Запуск игры

```bash
python main.py
```

## 🎯 Управление

| Клавиша | Действие |
|---------|----------|
| `1-5` | Выбор пункта меню |
| `↑` / `↓` | Навигация по меню |
| `Enter` | Активировать выбранный пункт |
| `Q` | Выход из игры |

## 📖 Структура проекта

```
QuestTest/
├── main.py          # Главный игровой цикл и обработка ввода (движок)
├── renderer.py      # Движок рендеринга и отрисовка кадров
├── scenario.json    # Картридж: сюжет, локации, тексты, переходы

```

## 🗺️ Локации (из scenario.json)

- **main_menu** - Главное меню с приветствием и выбором начала игры
- **room_start** - Стартовая комната с картой на стене и выходом в коридор
- **corridor** - Тёмный коридор с тупиком и блестящим предметом на полу

## ⚙️ Технические детали

### Рендеринг

Игра использует фиксированный холст 100×40 символов, разделённый на зоны:
- **Зона изображения** (12 строк) - ASCII-арт локации
- **Зона текста** (12 строк) - Описание ситуации
- **Зона меню** (10 строк) - 5 пунктов выбора

### Обработка эмодзи

Модуль `wcwidth` обеспечивает корректный расчёт ширины символов, включая эмодзи и специальные Unicode-символы.

## 🛠️ Разработка

### Добавление новой локации в scenario.json

Просто добавьте новую секцию в `scenario.json`:

```json
"new_location": {
  "art_id": "название_арта",
  "text": "Описание новой локации",
  "actions": [
    {"text": "Действие 1", "target": "другая_локация"},
    {"text": "Действие 2", "target": "ещё_одна_локация"}
  ]
}
```

Затем добавьте соответствующий ASCII-арт в `assets.py`:
```python
ASCII_ART["название_арта"] = """ваш арт"""
```

### Создание нового сценария (картриджа)

Скопируйте `scenario.json` и измените его содержимое — движок автоматически загрузит новый сюжет без изменения кода.
