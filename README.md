# QuestTest

**Версия: 0.1**

Тестовая квест-игра с консольным интерфейсом и поддержкой UTF-8/эмодзи.

## Реализация

### Версия 0.1

В данной версии реализован корректный рендеринг консоли с фиксированной шириной, обеспечивающий ровные границы независимо от наличия эмодзи и других многобайтовых символов.

#### Алгоритм выравнивания строк (`fix_line`)

Для решения проблемы разной визуальной ширины символов (особенно эмодзи) реализована функция `fix_line(text)`:

1. **Константы:**
   - `WIDTH = 100` — полная ширина рамки
   - `INNER_WIDTH = 98` — полезная ширина внутри рамок

2. **Логика функции `fix_line(text)`:**
   - Вычисляет визуальную ширину строки через `wcswidth(text)`
   - Если `wcswidth` возвращает `-1`, используется `len(text)` как fallback
   - Рассчитывает необходимое количество пробелов: `padding = 98 - visual_width`
   - Если `padding < 0`, текст обрезается до достижения ширины ≤ 98
   - Возвращает строку в формате: `|{text}{' ' * padding}|`

3. **Ключевые особенности:**
   - **Не используется** форматирование `f"{text:<98}"`, так как оно некорректно работает с эмодзи
   - Используется **ручное сложение**: текст + (пробелы × количество)
   - Символ `|` в конце строки **всегда** печатается на 100-й позиции

#### Применение в рендерере (`renderer.py`)

Все строки, выводимые на экран, проходят через `fix_line`:
- ASCII-арт
- Информационный текст
- Все 5 пунктов меню (включая 5-й)
- Разделительные горизонтальные линии: `"+" + "-"*98 + "+"`

#### Структура проекта

- `main.py` — точка входа, игровой цикл
- `renderer.py` — отрисовка интерфейса с функцией `fix_line`
- `logic.py` — игровая логика
- `assets.py` — ресурсы (тексты, арт)

## Запуск

```bash
python main.py
```
